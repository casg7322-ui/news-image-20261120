# Friday 20 November 2026: 46 sourced stories, 7 regions, with a date check

A one-page newspaper front page for Friday 20 November 2026: 46 stories drawn from that single day, across seven regions, with three illustrated lead stories, a stats strip, a numbered world map and a date-check strip that keeps Thursday's news off the page. Every headline is complete, every scheduled item is worded as scheduled, and disputed claims are attributed to their source rather than stated as fact.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies the rendered front page (`entry.png`) into `out/`.

## Fonts

The page is set in Gloock, Lora and Instrument Sans (all OFL), loaded from local TTF files as a build dependency — they come from the canvas-design skill's font set and are not vendored in this repo.
